# zquickm/tap

Homebrew tap for [UsageBar](https://github.com/zquickm/UsageBar) — macOS menu bar AI CLI token usage monitor.

```bash
brew install --cask zquickm/tap/usagebar
```

Installs without the Gatekeeper prompt (Homebrew downloads don't carry the quarantine attribute). New versions: update `version` + `sha256` in `Casks/usagebar.rb` on each release.
